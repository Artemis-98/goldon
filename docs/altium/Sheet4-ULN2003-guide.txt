چطور در Altium بسازی / بگذاری
------------------------------
روش سریع (پیشنهادی):
  1. در شیت Schematic: Place → Part  (یا P P)
  2. Manufacturer Part Search / Components panel
  3. جستجو: ULN2003AN  (یا ULN2003A)
  4. یک سمبل DIP-16 از TI یا ST بگیر و Place کن
  5. Designator را بگذار: U3
  6. نت‌ها را طبق جدول پایین وصل کن

روش دستی با فایل‌های این پوشه:
  A) Symbol Wizard
     - File → New → Library → Schematic Library
     - Tools → Symbol Wizard
     - Import / Paste از فایل: ULN2003AN-pins.csv
     - Layout: DIP Left/Right ، ۱۶ پین
     - Save به‌نام ULN2003AN.SchLib
  B) اسکریپت
     - یک SchLib جدید باز کن
     - File → Run Script → Create_ULN2003AN.pas
     - Save ، بعد Place → Part روی شیت ۴

================================================================================
مسیر سیگنال روی شیت
================================================================================

  U1.GPIO10 ──── net RLY1_IN_B ──── U3.1B
                                        │ (داخل چیپ)
                                   U3.1C ──── net RLY1_IN ──── K1.IN

  U1.GPIO11 ──── net RLY2_IN_B ──── U3.2B
                                        │
                                   U3.2C ──── net RLY2_IN ──── K2.IN

  +5V_BANK ──── U3.COM (پین۹) ، همچنین K1.VCC و K2.VCC
  GND      ──── U3.GND (پین۸) ، همچنین K1.GND و K2.GND

رله → پمپ (همان شیت):
  +3V_PUMP ──── K1.COM و K2.COM
  K1.NO ──── PUMP1.+
  K2.NO ──── PUMP2.+
  PUMP1.- و PUMP2.- ──── GND_PUMP

اشتباهات رایج
================================================================================
✗ GPIO مستقیم به IN رله
✗ COM (پین۹) را GND کردن — باید به +5V برود
✗ 5VIN ماژول رله را از 3.3V ESP گرفتن

✓ مسیر درست: GPIO → پایه B روی ULN → پایه C روی ULN → IN رله
