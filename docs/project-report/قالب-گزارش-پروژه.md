# قالب گزارش پروژه دانشجویی — گلدون هوشمند

> این فایل **اسکلت گزارش** است. جاهای `[...]` را با اطلاعات واقعی پر کنید.
> شمارهٔ صفحه، فونت و حاشیه را طبق آیین‌نامهٔ دانشکده تنظیم کنید.

---

## راهنمای شمارهٔ صفحه (پیشنهاد رایج)

| بخش                               | نوع شماره                | محل               |
| --------------------------------- | ------------------------ | ----------------- |
| جلد، صفحهٔ سفید، تقدیم            | بدون شماره               | —                 |
| صفحات ابتدایی (چکیده تا فهرست‌ها) | الف، ب، ج… یا i, ii, iii | پایین وسط         |
| از فصل ۱ تا آخر                   | ۱، ۲، ۳…                 | پایین وسط یا گوشه |

---

# ========== صفحات ابتدایی ==========

## ۱. جلد (Cover)

```
[نام دانشگاه]
[نام دانشکده]
[نام گروه / رشته]

پروژه پایانی دوره کارشناسی / کارپوشه / درس پروژه

عنوان پروژه:
سیستم آبیاری و پایش هوشمند گلدون (IoT)

نام دانشجو: [نام و نام خانوادگی]
شماره دانشجویی: [..........]

استاد راهنما: [نام و نام خانوادگی]
استاد مشاور (در صورت وجود): [..........]

[فصل / نیمسال] — [سال تحصیلی]، مثلاً بهار ۱۴۰۵
```

---

## ۲. صفحهٔ عنوان داخلی (Title Page)

همان اطلاعات جلد، با جزئیات بیشتر در صورت نیاز آیین‌نامه:

- عنوان فارسی + عنوان انگلیسی
- درجهٔ علمی مورد تقاضا (کارشناسی / کارشناسی‌ارشد)
- امضای دانشجو / استاد راهنما / مدیر گروه (اگر فرم جداگانه نیست)

**عنوان پیشنهادی (فارسی):**
طراحی و پیاده‌سازی سیستم پایش و آبیاری هوشمند گلدون مبتنی بر ESP32 و ارتباط بی‌سیم

**عنوان پیشنهادی (انگلیسی):**
Design and Implementation of a Smart Planter Monitoring and Irrigation System Based on ESP32 and Wireless Communication

---

## ۳. بسم‌الله / تقدیم (اختیاری)

صفحهٔ کوتاه تقدیم به خانواده / استاد / … — در بعضی دانشکده‌ها اختیاری است.

---

## ۴. سپاس‌گزاری (Acknowledgments)

نیم تا یک صفحه: تشکر از استاد راهنما، آزمایشگاه، هم‌تیمی‌ها، خانواده.

---

## ۵. چکیدهٔ فارسی

حدود **۱۵۰–۳۰۰ کلمه**، شامل:

1. مسئله و اهمیت
2. هدف پروژه
3. روش / معماری (برد حیاط، پنل، مودم، حسگرها)
4. نتیجهٔ کلیدی (چه چیزی ساخته و آزمایش شد)
5. ۳ تا ۵ **کلیدواژه**

**کلیدواژه‌های پیشنهادی:** اینترنت اشیاء، ESP32، آبیاری هوشمند، حسگر رطوبت خاک، رابط کاربری لمسی

---

## ۶. Abstract (انگلیسی)

همان محتوای چکیده، به انگلیسی + Keywords.

---

## ۷. فهرست مطالب

خودکار از عناوین فصل‌ها و زیربخش‌ها (در Word: References → Table of Contents).

---

## ۸. فهرست اشکال

شماره شکل + عنوان + صفحه
مثال: شکل ۳-۲ — دیاگرام ارتباط پنل، مودم و حیاط

---

## ۹. فهرست جداول

مثال: جدول ۴-۱ — پین‌مپ برد حیاط

---

## ۱۰. فهرست علائم و اختصارات (اختیاری ولی مفید)

| اختصار    | معنی                                        |
| --------- | ------------------------------------------- |
| IoT       | Internet of Things                          |
| UART      | Universal Asynchronous Receiver-Transmitter |
| OTA       | Over-The-Air                                |
| DHT       | Digital Humidity and Temperature sensor     |
| HTTP      | Hypertext Transfer Protocol                 |
| LCD / TFT | نمایشگر                                     |

# ========== بدنهٔ اصلی ==========

## فصل ۱ — مقدمه و کلیات

### ۱-۱ بیان مسئله

چرا آبیاری دستی/غیرهوشمند مشکل دارد؟ (مصرف آب، فراموشی، فاصله تا حیاط)

### ۱-۲ اهمیت و ضرورت

صرفه‌جویی آب، پایش از راه دور، کاربرد آموزشی IoT

### ۱-۳ اهداف پروژه

- هدف کلی
- اهداف جزئی (پایش خاک/هوا، کنترل پمپ/رله، پنل لمسی، پل مودم)

### ۱-۴ سوالات / فرضیات (در صورت نیاز آیین‌نامه)

### ۱-۵ محدوده و محدودیت‌ها

چه چیزهایی داخل پروژه است و چه چیزهایی نیست (مثلاً اپ موبایل، ابر، چندگلدان همزمان)

### ۱-۶ ساختار گزارش

یک پاراگراف کوتاه از محتوای هر فصل

---

## فصل ۲ — مبانی نظری و پیشینه

### ۲-۱ مفاهیم پایه

IoT، میکروکنترلر، حسگر، محرک (رله/پمپ)، شبکه محلی Wi-Fi، UART

### ۲-۲ سخت‌افزارهای مرتبط

ESP32 / ESP32-S3 / ESP32-C6، نمایشگر TFT، حسگر DHT، رطوبت خاک

### ۲-۳ کارهای مشابه / پیشینه

۲–۵ نمونه سیستم آبیاری هوشمند (مقاله، پروژه دانشگاهی، محصول تجاری) + مقایسه کوتاه

### ۲-۴ جمع‌بندی فصل

---

## فصل ۳ — تحلیل نیاز و طراحی سیستم

### ۳-۱ نیازمندی‌های کارکردی

لیست: خواندن حسگر، نمایش وضعیت، روشن/خاموش پمپ، ارتباط پایدار پنل↔حیاط

### ۳-۲ نیازمندی‌های غیرکارکردی

قابلیت اطمینان، تأخیر قابل قبول، مصرف انرژی نسبی، سادگی استفاده

### ۳-۳ معماری کلی

نمودار بلوکی:

```
پنل لمسی (برد ۲) --وای فای HTTP--> مودم (برد ۳) --UART--> حیاط (برد ۱)
                                      (+ نمایشگر C6 اختیاری)
```

### ۳-۴ طراحی سخت‌افزاری

نقش هر برد، پین‌مپ خلاصه، تغذیه، ایمنی رله

### ۳-۵ طراحی نرم‌افزاری

فریمورها، پروتکل فرمان/وضعیت، ساختار UI صفحات پنل

### ۳-۶ دیاگرام‌ها

- بلوکی
- ترتیب توالی (Sequence) برای یک فرمان ON/OFF
- شماتیک / سیم‌کشی (ارجاع به پیوست)

---

## فصل ۴ — پیاده‌سازی

### ۴-۱ محیط توسعه

Arduino IDE / PlatformIO، کتابخانه‌ها (TFT_eSPI، …)، ابزار آپلود

### ۴-۲ پیاده‌سازی برد حیاط

حسگرها، رله، حالت UART

### ۴-۳ پیاده‌سازی مودم (پل)

HTTP ↔ UART

### ۴-۴ پیاده‌سازی پنل کنترل

صفحات UI، لمس، کالیبراسیون

### ۴-۵ (اختیاری) برد نمایشگر C6

صفحات اسپلش / وضعیت

### ۴-۶ یکپارچه‌سازی و استقرار

مراحل راه‌اندازی در محل واقعی

---

## فصل ۵ — آزمایش، نتایج و ارزیابی

### ۵-۱ سناریوهای آزمون

جدول تست: مورد آزمون | ورودی | نتیجه مورد انتظار | نتیجه واقعی | وضعیت

### ۵-۲ نتایج حسگرها

نمونه داده‌های دما/رطوبت هوا و خاک (جدول یا نمودار)

### ۵-۳ نتایج فرمان‌ها

تأخیر فرمان پنل تا رله، پایداری ارتباط

### ۵-۴ بحث

نقاط قوت، ضعف، خطاهای مشاهده‌شده و رفع آن‌ها

---

## فصل ۶ — نتیجه‌گیری و کارهای آینده

### ۶-۱ خلاصه دستاوردها

### ۶-۲ محدودیت‌های نهایی

### ۶-۳ پیشنهاد ادامه کار

اپ موبایل، داشبورد وب، آبیاری زمان‌بندی‌شده، چند ناحیه، اعلان، مصرف انرژی بهینه

# ========== صفحات پایانی ==========

## منابع و مآخذ

سبک استناد طبق آیین‌نامه (معمولاً IEEE یا APA یا Vancouver دانشکده).

نمونه دسته‌ها:

- کتاب / جزوه میکروکنترلر و IoT
- دیتاشیت ESP32، DHT، نمایشگر
- مقالات آبیاری هوشمند
- مستندات کتابخانه‌های نرم‌افزاری
