  • شبکه خانه: X28-2.4G-94A50A · رمز OTA: ota2026

۳. ماژول SIM800L EVB روی برد ۱

ماژول GSM روی برد حیاط (ESP32-S3). ترتیب پین‌ها روی هدر برد EVB از چپ به راست (طبق سیم‌کشی پروژه):

5VIN · GND · VDD · TXD · RXD · GND · RST

نام پایه‌ها و نقش هر کدام

نام پایه معنی نقش
5VIN ۵ ولت ورودی ماژول تغذیه قدرت RF/GSM — جریان لحظه‌ای بالا
GND زمین (اولین) مرجع تغذیه و سیگنال
VDD سطح منطقی I/O تعیین ولتاژ UART/منطق — باید ۳.۳V باشد
TXD Transmit Data (خروجی ماژول) داده از SIM به ESP — به RX برد وصل می‌شود
RXD Receive Data (ورودی ماژول) داده از ESP به SIM — از TX برد می‌آید
GND زمین (دومین) همان GND مشترک؛ هر دو پایه یکی‌اند
RST Reset ریست سخت‌افزاری ماژول (اختیاری)

اتصال به ESP32-S3 حیاط

پایه SIM800L وصل به رنگ سیم (راهنما) توضیح
5VIN خروجی ۵V پاوربانک (نه پین ۵V خود ESP) قرمز منبع حداقل ۵V/۲A · خازن ۱۰۰۰µF موازی بین 5VIN و GND نزدیک ماژول
GND (اول) GND مشترک مشکی همراه پایه − خازن
VDD ESP32 3.3V آبی روشن سطح منطقی UART — هرگز ۵V نده
TXD ESP32 GPIO16 (RX) زرد SIM TX → ESP RX · ضربدری
RXD ESP32 GPIO17 (TX) سبز ESP TX → SIM RX · ضربدری
GND (دوم) GND مشترک مشکی همان زمین؛ اتصال دوم اختیاری ولی توصیه‌شده
RST ESP32 GPIO18 (اختیاری) نارنجی ریست نرم‌افزاری — در فریمور تست: firmware/sim800l_test

− (کوتاه / نوار تیره) SIM GND

موازی روی تغذیه، حداکثر ۲–۳ سانتی‌متر از پین‌های ماژول — برای جهش جریان هنگام ارسال GPRS.

  • UART همیشه ضربدری است: TXD ماژول → RX میکرو · RXD ماژول ← TX میکرو.
  • آنتن روی سوکت IPEX خود ماژول؛ سیم جدا به GPIO ندارد.
  • تداخل GPIO18: در سیم‌کشی، RST سیم به GPIO18 است؛ در yard_api فعلی WATER هم روی GPIO18 تعریف شده. اگر هر دو لازم‌اند، یکی را جابه‌جا کن (شماتیک سطح‌آب را روی GPIO7 گذاشته).
  • تست AT: firmware/sim800l_test با baudهای ۹۶۰۰ / ۱۱۵۲۰۰ و …

۹. پروتکل و API

HTTP روی مودم (و حیاط در حالت وای فای)

متد / مسیر عمل
GET /status وضعیت سنسورها و رله‌ها (JSON)
GET /relay?n=1|2&state=0|1|toggle کنترل پمپ
GET /ai?state=0|1|toggle حالت خودکار AI
GET /dhtscan اسکن / بایند DHT

UART خط‌به‌خط (مودم ↔ حیاط)

Modem→Yard: STATUS Modem→Yard: RELAY,1,1 / RELAY,2,0 Modem→Yard: AI,toggle / AI,1 / AI,0 Yard→Modem: {"ok":true, ... } (یک خط JSON + \\n)

مودم همان API HTTP را نگه می‌دارد و پشت صحنه با UART به حیاط پروکسی می‌کند.

۱۰. آپلود و FQBN

برد روش آپلود FQBN / اسکریپت
#1 حیاط (UART) فقط USB
esp32:esp32:esp32s3:CDCOnBoot=default,FlashSize=8M,PSRAM=disabled,PartitionScheme=default_8MB,USBMode=hwcdc,UploadSpeed=115200
#1 حیاط (وای فای) OTA با ota2026 همان FQBN بالا · hostname goldon-yard
#2 پنل USB (نمونه COM14) esp32:esp32:esp32 · اسکریپت scripts/upload_panel.ps1
#3 مودم USB یا OTA بعد از آنلاین همان FQBN حیاط (ESP32-S3) · host goldon-modem
#4 C6 USB (نمونه COM15)
esp32:esp32:esp32c6:CDCOnBoot=cdc,FlashSize=4M,PartitionScheme=default,UploadSpeed=921600
اسکریپت: scripts/upload_c6_splash.ps1 -Port COM15
